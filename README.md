# CUTIE STREET X monitor

ログイン済みのXプロフィールをWindows PCから手動取得し、前回保存時との差分をGitHubへ期限なしで保存します。

## 初回設定

1. `setup-local.cmd` をダブルクリックします。
2. 完了後、`run-local.cmd` をダブルクリックします。
3. 専用ブラウザーが開いたらXへログインします。
4. ログイン完了後、黒い実行画面に戻ってEnterキーを押します。

ログイン状態は `%LOCALAPPDATA%\cutie-street-monitor\browser-profile` に保存されます。このフォルダーはGitHubへ送信されません。

## 普段の実行

`run-local.cmd` をダブルクリックします。最新投稿からスクロールし、`archive.json` に保存済みの投稿と重なる地点まで遡ります。新規・変更投稿を保存した後、データファイルをGitHubへ自動送信します。

取得済み投稿と `coverage_events` は日数による削除を行わず、期限なしで保持します。

実行間隔が長すぎる場合、削除済み投稿やXがタイムラインに表示しない投稿は回収できないことがあります。保存済み投稿との重複地点に到達できなかった場合は、取得漏れの可能性が `coverage_events` に記録されます。

## 診断情報

取得に失敗した場合、URL、HTTPステータス、HTML、本文、スクリーンショットを `diagnostics` フォルダーへ保存します。ログイン情報を保持するブラウザープロファイルは診断フォルダーには含まれません。
