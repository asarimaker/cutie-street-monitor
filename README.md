# CUTIE STREET X monitor

通常のGoogle Chromeにログイン済みのXプロフィールをWindows PCから取得し、前回保存時との差分をGitHubへ期限なしで保存します。

## 初回設定

1. 通常のGoogle ChromeでXへログインしておきます。
2. `setup-local.cmd` をダブルクリックします。
3. Chromeの拡張機能画面で「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選び、エクスプローラーで同時に開いた `chrome-extension` フォルダーを指定します。
5. 拡張機能一覧に「CUTIE STREET Local Monitor」が表示されたら設定完了です。

拡張機能は通常Chromeの既存ログインを利用します。パスワードやCookieを読み出したり、GitHubへ送信したりしません。

## 普段の実行

`run-local.cmd` をダブルクリックします。通常ChromeでCUTIE STREETのプロフィールが開き、拡張機能が最新投稿から自動スクロールします。`archive.json` に保存済みの投稿と重なる地点まで遡り、新規・変更投稿を保存した後、データファイルをGitHubへ自動送信します。

取得済み投稿と `coverage_events` は日数による削除を行わず、期限なしで保持します。

実行間隔が長すぎる場合、削除済み投稿やXがタイムラインに表示しない投稿は回収できないことがあります。保存済み投稿との重複地点に到達できなかった場合は、取得漏れの可能性が `coverage_events` に記録されます。

## ローカル通信

拡張機能は実行中だけ `127.0.0.1:8765` の監視処理と通信します。毎回ランダムに生成する一時トークンが一致した場合だけ、公開プロフィールに表示された投稿情報を受け付けます。ログイン情報は送信しません。

Chrome右下に青い進捗表示が出ます。緑色の完了表示になった後、PowerShell側で差分の保存とGitHubへの送信が行われます。
